Interactions, clashes and model quality for PDB and mmCIF models. Heavy-atom analysis, no licence needed. Choose what you are checking, then upload the files.

Structure file

One file, plain text only. Archives (zip, gz) are not accepted. Only the first model is analysed.

AlphaFold JSON files (optional, recommended)

Use the files of the same model as the .cif. Without them the report has no AI metrics or PAE plot.

Chains to analyse

"auto" uses the pair with the largest interface.

Ligand

Single ions such as MG are listed too. Model type (prediction or experiment) is detected from the file.

Chains

Nothing selected means every chain.

Output
Clash check
NMR ensemble
Predicted complex. AI confidence metrics; interface interactions, with clashes listed separately; quality of the prediction (pLDDT, clashes, backbone geometry).
Experimental interface. Interface interactions; model quality with B-factors, waters, clashes and backbone geometry.
Ligand. Interaction map, contacts by residue and water, hydrogen-bond and clash verdicts for one ligand.
Chain quality. One block per chain, plus a comparison table when several chains are chosen.
